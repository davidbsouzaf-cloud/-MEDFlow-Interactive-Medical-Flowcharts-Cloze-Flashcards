MedFlow – Image Node and Collapsible Sidebar Update

Image nodes behave like regular flowchart nodes: they can be moved, resized, connected from four sides, and use the same Apply / +1 cloze numbering.

Paste an image with Ctrl+V to create an image node. If an image node is selected, Ctrl+V replaces its image. Text paste remains unchanged while editing text. The image frame closely fits the image aspect ratio with minimal padding.

The sidebar can be collapsed and expanded using the chevron control. The Delete selected button has been removed from the sidebar; the Delete key shortcut remains available.

Install: back up your add-on, then replace __init__.py, medflow_editor.html, card_templates.html, and style.css with the files in this package. Test on a duplicate note/collection first.
